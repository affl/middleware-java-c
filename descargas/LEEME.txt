Archivos:
  Client_v1_0.java
  server_v1.0.c

Ambos archivos utilizan el puerto 5001, que fue el ajuste realizado
para evitar el conflicto con el puerto 5000 en macOS.

En la primera terminal, dentro de esta carpeta:
  clang server_v1.0.c -o servidor
  ./servidor

En la segunda terminal, dentro de esta misma carpeta:
  javac Client_v1_0.java
  java Client_v1_0

Operaciones disponibles:

  1. Addition (suma de matrices)
  2. Greatest (mayor valor de un vector)
  3. Exit (salir)

El servidor utiliza fork() para atender conexiones en procesos hijos.
El cliente usa flujos de datos binarios para comunicarse por TCP.

GitHub Pages permite descargar los archivos, pero la ejecución real se realiza en una computadora con Java y un compilador C.
