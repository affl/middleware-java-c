01 / FUNDAMENTOS

¿Por qué hablamos de middleware ?

Los sistemas distribuidos conectan componentes independientes. Para colaborar, necesitan intercambiar información de forma comprensible para ambos.

01
▦

Sistema distribuido

Varios programas o equipos cooperan mediante mensajes, aunque se ejecuten de manera independiente.

02
⇄

Interoperabilidad

Java y C tienen estructuras diferentes, pero pueden entenderse si acuerdan cómo representar los datos.

03
⌁

Middleware y TCP

La comunicación mediante sockets ofrece un mecanismo básico para construir servicios remotos entre ambos programas.

Precisión conceptual: este proyecto demuestra mecanismos de comunicación usados para construir middleware; no implementa una plataforma completa de middleware.

El cliente empaqueta la solicitud y espera los datos que devuelve C.

server_v1.0.c 
// Sumar matrices aplanadas
void addition(const float *a,
              const float *b,
              float *r, int n) {
    int total = n * n;
    for (int i = 0; i < total; i++) {
        r[i] = a[i] + b[i];
    }
}

El servidor calcula cada posición y prepara la matriz de respuesta.

Detalle del servidor del equipo

La implementación utiliza fork() para atender clientes en procesos separados, además de funciones de lectura y escritura completas. Es una característica adicional, no necesaria para comprender las dos operaciones.
